[font=Verdana][size=5][color=#1e84cc][b]Features[/b][/color][/size][/font]
[list]
[*][font=Verdana][b]ESP-less[/b] [color=#a0a0a0]- no plugin in your load order[/color][/font]
[*][font=Verdana][b]Individual names[/b] [color=#a0a0a0]- every generic NPC gets its own name, even when many share one record. Names match the NPC's sex, and nearby NPCs never share a name[/color][/font]
[*][font=Verdana][b]Consistent[/b] [color=#a0a0a0]- names stay the same for the whole playthrough. A new game gives new names[/color][/font]
[*][font=Verdana][b]Dialogue window[/b] [color=#a0a0a0]- shows the new name[/color][/font]
[*][font=Verdana][b]Name pools[/b] [color=#a0a0a0]- about 1,500 names for 287 roles: Wasteland, Legion (Latin), Ghoul, Tribal, Chinese, Super mutant, Swampfolk and Kids[/color][/font]
[*][font=Verdana][b]TTW compatible[/b] [color=#a0a0a0]- New Vegas, its DLCs and the Fallout 3 side of TTW[/color][/font]
[*][font=Verdana][b]Save friendly[/b] [color=#a0a0a0]- install mid-game. Only one number goes in your save, so uninstalling is clean[/color][/font]
[*][font=Verdana][b]Unique NPCs[/b] [color=#a0a0a0]- keep their names. Only the generic NPCs in the rules files are renamed[/color][/font]
[/list]
[line]
[font=Verdana][size=5][color=#1e84cc][b]Settings[/b][/color][/size]
[color=#a0a0a0]In MCM or the INI.[/color][/font]
[list]
[*][font=Verdana][b]Enabled[/b] [color=#a0a0a0]- off gives NPCs their original names back[/color][/font]
[*][font=Verdana][b]Use titles[/b] [color=#a0a0a0]- [i]Ranger Barker[/i] (on) or [i]Erik Barker[/i] (off)[/color][/font]
[*][font=Verdana][b]Show role after name[/b] [color=#a0a0a0]- [i]Henry Glover (Powder Ganger)[/i][/color][/font]
[*][font=Verdana][b]First names only[/b] [color=#a0a0a0]- [i]Henry[/i] instead of [i]Henry Glover[/i][/color][/font]
[*][font=Verdana][b]Scan interval[/b] [color=#a0a0a0]- how often to look for new NPCs (default 10 seconds)[/color][/font]
[*][font=Verdana][b]Name seed[/b] [color=#a0a0a0]- change it to give every NPC a new name (MCM only)[/color][/font]
[/list]

[font=Verdana][size=5][color=#1e84cc][b]Compatibility[/b][/color][/size][/font]
[list]
[*][font=Verdana][b]Mods that rename NPCs[/b] [color=#a0a0a0]- compatible. NPCs that already have a new name are left alone[/color][/font]
[*][font=Verdana][b]Mods that add NPCs[/b] [color=#a0a0a0]- not named, unless there's an add-on for them[/color][/font]
[*][font=Verdana][b]Translated games[/b] [color=#a0a0a0]- need a translation, see Translations[/color][/font]
[/list]
[font=Verdana]If names look wrong, check [b]NamesOfTheMojave.log[/b] in the game folder (or [i]overwrite/Root/[/i] with MO2 Root Builder). It lists every NPC that was named and any bad rule lines.[/font]
[line]
[font=Verdana][size=5][color=#1e84cc][b]Translations[/b][/color][/size][/font]
[font=Verdana]A translation replaces the files in two folders. It is a [b]replacement[/b], not an add-on.[/font]
[list]
[*][font=Verdana][url=https://github.com/Noklef/NamesOfTheMojave/tree/main/src/Config/NamesOfTheMojave/Rules]Rules[/url] [color=#a0a0a0]- the in-game names to match[/color][/font]
[*][font=Verdana][url=https://github.com/Noklef/NamesOfTheMojave/tree/main/src/Config/NamesOfTheMojave/Names]Names[/url] [color=#a0a0a0]- the name lists[/color][/font]
[/list]
[font=Verdana]Each folder has a README that explains its files. The data came from [url=https://github.com/Noklef/NamesOfTheMojave/tree/main/tools/xedit]two xEdit scripts[/url], which should also work on a translated game. Send me a link to your translation and I'll add it here.[/font]
