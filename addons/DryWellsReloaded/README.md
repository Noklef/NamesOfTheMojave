# Names of the Mojave - Dry Wells Reloaded add-on

Names the generic NPCs that Dry Wells Reloaded (`DryWellsReloaded.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, Dry Wells Reloaded. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/DryWellsReloaded.txt` allows actors from `DryWellsReloaded.esm`. With it alone, actors with core names (Prime, Recruit and Veteran Legionary, Slave, ...) get names.
- `Rules/50_DryWellsReloaded.txt` adds 12 generic names (Hunters' Guild Member, Legion Slavemaster, Villa Resident, ...). Escaped Slave also matches 4 Fallout 3 random-encounter NPCs, so those get names too.
- Not named: characters with their own name (Decanus Milo, Recruit Nemo, ...), corpse labels (Dead Hunter).

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
