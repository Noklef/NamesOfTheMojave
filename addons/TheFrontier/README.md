# Names of the Mojave - The Frontier add-on

Names the generic NPCs that The Frontier (`The Frontier.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, The Frontier. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/TheFrontier.txt` allows actors from `The Frontier.esm`. With it alone, actors with core names (Scavenger, Slaver, NCR Trooper, Veteran Legionary, Enclave Soldier, ...) get names.
- `Rules/50_TheFrontier.txt` adds 98 generic names (Scav, Crusader, Man-At-Arms, Sopher, Ice Fiend, Militiaman Hunter, ...). Legion roles use the Legion pool and ghoul roles the ghoul pool. None of these names exist in Fallout 3, Fallout: New Vegas, their DLCs or TTW.
- Not named: characters with their own name (Badger, Siren, AJ, ...), corpse labels (Dead ...), names used only by corpses, Lobotomites, androids, robots and holograms, the hallucination NPCs (Lost, Merc), Child. Rules match by name, so a few records under a named role are named too: 3 robot-race `Scav` records and 4 child `Militiaman` records.

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
