# Names of the Mojave - TweaksTTW add-on

Names the generic NPCs that TweaksTTW (`TweaksTTW.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, TweaksTTW. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/TweaksTTW.txt` allows actors from `TweaksTTW.esm`. With it alone, actors with core names (Raider, Slave, Talon Company Merc, Enclave Hellfire Trooper, Enclave Officer) get names.
- `Rules/50_TweaksTTW.txt` adds 4 generic names: Rivet City Resident, Fairfax Freak, Littlehorn & Associates Representative, Regulator Representative.
- Not named: Target (the contract target: the label shows who to hunt).

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
