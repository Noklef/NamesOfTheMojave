# Names of the Mojave - Trooper Uncut add-on

Names the generic NPCs that Trooper Uncut (`Trooper Uncut.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, Trooper Uncut. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/TrooperUncut.txt` allows actors from `Trooper Uncut.esm`. With it alone, actors with core names (NCR Trooper, NCR Recruit, Omerta Thug, Van Graff Thug, Escort, Mojave Inhabitant, White Glove, ...) get names.
- `Rules/50_TrooperUncut.txt` adds 5 generic names: Chairwoman, Garret Thug, Great Khan Ritemaster, Mojave Inhabitant Leader, NCR Lieutenant.
- Not named: Benny (his own name), Assistant (a Fallout: New Vegas NPC has this name too, role not clear).

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
