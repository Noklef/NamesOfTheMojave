# Names of the Mojave - Gary add-on

Gives Vault 108's Gary clones Gary-ish names, e.g. `Gareth (Gary 42)` or `Not Not Gary (Gary 17)` with Show role on. Fallout 3 / TTW only.

Requires: Names of the Mojave. Install the `Config` folder as its own mod, after Names of the Mojave. No `Plugins/` file: the Garys come from plugins the core mod already lists.

- `Rules/50_Gary.txt` adds 14 names: Gary 1, 12, 17, 23, 25, 27, 29, 32, 33, 36, 41, 42, 43 and 47 (every Gary record in Fallout3.esm and Anchorage.esm).
- `Names/GARY_vault108/` (31 names): Gary, Garry, Gareth, Big Gary, Angry Gary, Not Not Gary, Spare Gary, Gary 2.0, ...

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
