# Names of the Mojave - Gary add-on

Gives Vault 108's Garys Gary-ish names, e.g. `Gareth (Gary 42)` or `Not Not Gary (Gary 17)` with Show role on. Fallout 3 / TTW only.

Requires: Names of the Mojave 1.2 or later (wildcard rules). Install the `Config` folder as its own mod, after Names of the Mojave. No `Plugins/` file: the Garys come from plugins the core mod already lists.

- `Rules/50_Gary.txt` has one wildcard rule, `Gary *`, for every Gary in Fallout3.esm and Anchorage.esm (Gary 1 to Gary 47). `Gary Staley|-` keeps Rivet City's Gary Staley out of it.
- `Names/GARY_vault108/` (51 names): Gary, Garry, Gareth, Big Gary, Angry Gary, Not Not Gary, Spare Gary, Gary 2.0, ...

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
