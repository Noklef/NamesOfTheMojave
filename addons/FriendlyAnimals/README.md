# Names of the Mojave - Friendly Animals add-on

Gives brahmin, bighorners and guard dogs names, e.g. `Bessie (Brahmin)` or `Buster (Legion Mongrel)` with Show role on. Covers Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave. Install the `Config` folder as its own mod, after Names of the Mojave. No `Plugins/` file: the animals come from plugins the core mod already lists.

- `Rules/50_FriendlyAnimals.txt` adds 27 names:
  - Livestock: Brahmin, Brahmin WaterSkins, Pack Brahmin, Malnourished Brahmin (and Calf), Water Brahmin, Fiend Brahmin.
  - Bighorners (they graze and only fight when you get close): Young Bighorner (Goodsprings), Bighorner (and Calf, Bull), Malnourished Bighorner (and Calf), Mountain Bighorner (and Calf, Bull; Honest Hearts).
  - Dogs: Legion Mongrel, NCR Guard Dog, Raider Guard Dog, Fiend Guard Dog, Talon Company Guard Dog, Guard Dog (Anchorage), Scavenger's Dog, Prospector's Dog, and three more.
- `Names/ANIMALS_brahmin/` (45 names), `Names/ANIMALS_bighorner/` (33 names) and `Names/ANIMALS_dog/` (50 names): pet names and a few jokes. No list uses a name that the games already give a character.
- Not named: wild animals that hunt you (Vicious Dog, Wild Dog, Coyote, ...), names shared with them (Dog), and animals with their own name (Rex, Dogmeat, Betsy the Brahmin, Hoff's Pack Brahmin, Mountain Bighorner Mother, ...).

Built from an FNVEdit export (`tools/xedit/NotM_ExportCreatures.pas`).
