# Names of the Mojave - Long 15 Reloaded add-on

Names the generic NPCs that Long 15 Reloaded (`Long15Reloaded.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, Long 15 Reloaded. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/Long15Reloaded.txt` allows actors from `Long15Reloaded.esm`. With it alone, actors with core names (NCR Trooper, Mercenary, NCR MP, Junkie, ...) get names.
- `Rules/50_Long15Reloaded.txt` adds 37 generic names (Casa Stanton Guard, Morton Mercenary, Baker Resident, ...).
- Not named: characters with their own name, corpse labels (Dead ...), names used only by corpses, Lobotomites (an undecided group in the core mod).

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
