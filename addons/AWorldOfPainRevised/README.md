# Names of the Mojave - A World of Pain Revised add-on

Names the generic NPCs that A World of Pain Revised (`A World of Pain Revised.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, A World of Pain Revised. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/AWorldOfPainRevised.txt` allows actors from `A World of Pain Revised.esm`. With it alone, actors with core names (Wastelander, NCR Trooper, NCR Ranger, Powder Ganger, ...) get names.
- `Rules/50_AWorldOfPainRevised.txt` adds 2 generic names: Powder Ganger Outcast and Ghoul Raider.
- Not named: characters with their own name (Craze, Frost, Ranger Guerra, ...), names used only by corpses (Vault Squatter, Ghoul Adventurer, ...).

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
