# Names of the Mojave - New California add-on

Names the generic NPCs that New California (`NewCalifornia.esm`) adds. Separate from the core mod, which covers only Fallout 3, Fallout: New Vegas, their DLCs and TTW.

Requires: Names of the Mojave, New California. Install the `Config` folder as its own mod, after Names of the Mojave.

- `Plugins/NewCalifornia.txt` allows actors from `NewCalifornia.esm`. With it alone, actors with core names (NCR Trooper, NCR Ranger, Raider, Enclave Soldier, Enclave Officer, Local, Mercenary, ...) get names.
- `Rules/50_NewCalifornia.txt` adds 79 generic names (Survivalist Raider, Viper Raider, Psycho Raider, Black Vulture Raider, Vault Viking Raider, Road Bandit, Enclave Patriot, Vault 18 Security Officer, ...). Shi use the Chinese pool, tribals the tribal pool, ghouls the ghoul pool and children the kids pool.
- Not named: characters with their own name (Terra Mayson, Annai Oran, Chevy Bragg, ...), gang leaders, corpse labels (Dead ...), names used only by corpses (Odyssey Resident, Treasure Hunter, Mutated Enclave Scientist), Infected Savage, test and preset records. Also Innkeeper and Shi Bank Representative (the plugin's names end with a space) and one `Elite Psycho Raider` record spelled with an accented E.

Built from an FNVEdit export (`tools/xedit/NotM_ExportNPCs.pas`).
